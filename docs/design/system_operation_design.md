System Design of a Counter-Timed Finite State MachineA practical illustration of the concepts previously examined (FSM structure, Moore-type output logic, synchronous clocking, and counter-based timing) is a simple traffic-light controller. The design demonstrates how an FSM, driven by a global clock and assisted by a timing counter, produces a deterministic cyclic sequence of outputs.Description of System OperationThe controller manages three mutually exclusive light signals (Red, Yellow, Green). Operation begins in the Red phase. A binary counter, clocked by the system clock, measures the duration of the current phase. When the counter reaches a predetermined limit associated with that phase, a “done” flag is asserted. On the subsequent clock edge the FSM advances to the next state, the counter is reset, and timing of the new phase begins. The sequence Red → Green → Yellow → Red repeats indefinitely. All state changes and output updates occur synchronously with the system clock, ensuring deterministic behaviour free from race conditions.Identification of Required FSM StatesThree principal states are defined:
S_RED — Red light active
S_GREEN — Green light active
S_YELLOW — Yellow light active
These states encode the essential modes of the controller. The timing counter itself is external to the FSM state encoding; it supplies only the Boolean condition that enables a transition. A Moore-style output function is employed, so the light signals depend solely on the present state.State DiagramThe state diagram consists of three nodes connected in a unidirectional cycle. Each node contains a self-loop conditioned on the negation of the “done” signal (i.e., while the counter has not yet expired). A single transition leaves each node when the corresponding counter limit is reached:
S_RED advances to S_GREEN on “done”
S_GREEN advances to S_YELLOW on “done”
S_YELLOW advances to S_RED on “done”
The diagram therefore expresses both the sequential order of the phases and the dependence of each transition on the expiration of a timed interval.
